## Margin Protection

### Controlled Economy
- Coin-to-INR rate adjustable server-side
- Ad reward coins can be dynamically modified
- Level progression gates prevent excessive payouts
- Daily ad limits cap maximum earnings

### Revenue Optimization
1. **Ad Mediation**: Use AdMob mediation with multiple ad networks to maximize fill rate and eCPM
2. **Frequency Capping**: Cooldown between ads prevents revenue dilution
3. **User Segmentation**: Higher-value users see more premium ad placements
4. **Retention Features**: Daily bonuses, streaks, and gamification increase DAU

### Cost Controls
1. **Withdrawal Minimums**: ₹55 minimum prevents micro-withdrawals
2. **Admin Approval**: Manual review prevents fraudulent withdrawals
3. **KYC Gates**: Higher withdrawal amounts require identity verification
4. **Anti-Fraud**: VPN/emulator detection prevents multi-accounting

## Growth Strategy

### User Acquisition
1. **Viral Referral System**: 10% ongoing referral earnings incentivize sharing
2. **WhatsApp Sharing**: Native sharing to India's dominant messaging platform
3. **Social Proof**: Withdrawal screenshots shared by users
4. **ASO Optimization**: App Store Optimization for discovery

### Retention
1. **Daily Login Bonuses**: Increasing rewards for consecutive logins
2. **Streak System**: Gamified daily engagement
3. **Level Progression**: Unlocking new features keeps users engaged
4. **Achievement Badges**: Collection mechanics for long-term retention
5. **Spin Wheel & Scratch Cards**: Gamified daily rewards

### Scalability
1. **Firebase + MongoDB**: Horizontally scalable database architecture
2. **CDN**: Static asset delivery optimization
3. **Rate Limiting**: Protection against abuse at scale
4. **Microservices Ready**: Backend can be split into services as needed
